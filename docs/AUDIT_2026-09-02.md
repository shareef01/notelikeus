## New findings

### P2 — Sync / data integrity

| ID | Area | Description | Location | Recommended fix |
|---|---|---|---|---|
| **AUD2-01** | Web realtime | Empty Firestore snapshot still calls `applyNotes([])` when `knownRemoteIds.size > 0`. Delete-on-absence logic is guarded; UI wipe is not. User sees total data loss until reconcile. | `web/src/lib/notes/notesSyncService.ts:176–188` | Skip `applyNotes` when `remoteNotes.length === 0 && knownRemoteIds.size > 0`; surface same error as `syncNotesWithCloud` |
| **AUD2-02** | Web upload | `uploadAllNotes` has no empty-cloud guard. Failed-open `fetchRemoteNotes` → empty array → all eligible locals upload, including imports with `serverUpdatedAt: null` that lose to confirmed remotes only when remote is actually fetched. | `web/src/lib/firestore/notesRepository.ts:182–202` | Throw when `remoteNotes.length === 0 && previouslyKnownCloudIds.size > 0` (pass known IDs from caller) |
| **AUD2-03** | Kotlin sync | `uploadNote` (debounced per-note path) lacks the `knownCloudIds` null-fetch guard present in `reconcileUploads`. Stale local edit can overwrite cloud when per-note fetch fail-opens. | `composeApp/.../NoteSyncEngine.kt:203–211` | Mirror `reconcileUploads` lines 174–176 before `putNote` |

## Security assessment (summary)

### Strengths
- Owner-scoped Firestore rules with field whitelisting, size bounds, server-timestamp enforcement
- Android: minimal export surface, intent tokens, SQLCipher + Keystore quarantine, `FLAG_SECURE`, notification privacy
- Web: React text rendering, `toSafeHref`, strict CSP (with documented `unsafe-inline` style tradeoff), SW origin validation
- No committed private keys; backup validation on Kotlin; sign-out clears memory + Firestore cache

### Residual risks (new or emphasized)
1. **AUD2-01–03** — Incomplete empty-cloud guards on realtime and per-note/upload paths
2. **AUD2-07–08** — Web session/cache isolation gaps on shared devices
3. **AUD2-04** — Unbounded share-target payload on Android
4. CSP `style-src 'unsafe-inline'` weakens XSS containment (documented tradeoff)

---

## Recommendations (priority order)

1. **Fix AUD2-01–03** — Add regression tests mirroring existing `SuspectEmptyCloudException` / `notesSync.emulator.test.ts` coverage
2. **Fix AUD2-07–08** — Purge Firestore cache on account switch and auth loss; clear local user data on `enterGuestMode()`
3. **Fix AUD2-09** — Drawer focus trap parity with `LabelsScreen` / `AuthScreen`
4. **Fix AUD2-11–12** — Port Kotlin backup depth/label caps to web `importBackup.ts`
5. **Re-run** `docs/PIXEL_QA_CHECKLIST.md` before mobile release tag
